Mein Konto

Zwei-Faktor-Anmeldung

Zusätzlich zum Passwort fragt das Panel nach einem Code aus einer Authenticator-App (z. B. Aegis, 2FAS, Google Authenticator, Bitwarden). Wer dein Passwort kennt, kommt so trotzdem nicht hinein.

Angemeldete Geräte

Benutzer und Rechte

Weitere Konten für Freunde oder Mit-Admins. Zuschauer sehen Server, Konsole und Verlauf. Betreiber dürfen Server starten, stoppen, Befehle senden, Backups, Dateien, Einstellungen und Mods. Admins dürfen alles. Betreiber und Zuschauer lassen sich auf einzelne Server beschränken.

HTTPS

Verschlüsselt die Verbindung zum Panel, damit Passwörter nicht mitgelesen werden können. HTTP und HTTPS laufen auf demselben Port; ist HTTPS an, wird http:// automatisch umgeleitet.

Der Browser warnt beim ersten Aufruf, weil niemand das Zertifikat beglaubigt. Einmal „Trotzdem fortfahren“ wählen; die Verbindung ist danach trotzdem verschlüsselt.

Die Domain muss auf deine öffentliche IP zeigen. Im Router Port 80 (für die Prüfung) und Port 443 auf Port 8420 dieses Rechners weiterleiten – dann ist das Panel unter https://deine-domain erreichbar. Das Zertifikat wird alle 60 Tage von selbst erneuert.

Ausgesperrt? Auf dem Server selbst geht http://localhost:8420 immer, z. B. per SSH-Tunnel. Oder in /etc/systemd/system/gamepanel.service die Zeile Environment=GP_NO_TLS=1 ergänzen und den Dienst neu starten.

KI-Assistent

Du nutzt deinen eigenen API-Key. Die Kosten rechnet dein Anbieter direkt mit dir ab. Ollama läuft kostenlos auf deinem eigenen Rechner.

Externe Backups

Jedes Backup wird zusätzlich außerhalb dieses Servers gespeichert. Fällt die Platte aus, sind die Spielstände noch da.

Steam-Konto

Nur für Spiele, deren Server Steam nicht anonym herausgibt (Arma 3, DayZ, Killing Floor …). Das Panel speichert dein Passwort nicht, SteamCMD merkt sich nur die Anmeldung. Am besten ein eigenes Konto nur für Server nehmen: wer mit demselben Konto spielt, kann beim Server-Update aus dem Spiel fliegen. Manche Spiele (z. B. DayZ) verlangen, dass das Konto das Spiel besitzt.

Lizenz

Selbsttest

Prüft automatisch, ob die Spielvorlagen auf diesem Rechner funktionieren: herunterladen, starten, auf Bereitschaft und Spielerabfrage warten, wieder löschen. Läuft im Hintergrund, auch über Nacht.

Selbsttest

Ein Spiel nach dem anderen, kleine Downloads zuerst. Jeder Testserver wird danach samt Dateien gelöscht. Deine eigenen Server bleiben unberührt, sollten aber nicht dieselben festen Ports belegen.
