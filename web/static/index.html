          Mein Konto

          Zwei-Faktor-Anmeldung

          Zusätzlich zum Passwort fragt das Panel nach einem Code aus einer Authenticator-App (z. B. Aegis, 2FAS, Google Authenticator, Bitwarden). Wer dein Passwort kennt, kommt so trotzdem nicht hinein.

          Angemeldete Geräte

          HTTPS

          Verschlüsselt die Verbindung zum Panel, damit Passwörter nicht mitgelesen werden können. HTTP und HTTPS laufen auf demselben Port; ist HTTPS an, wird http:// automatisch umgeleitet.

          Der Browser warnt beim ersten Aufruf, weil niemand das Zertifikat beglaubigt. Einmal „Trotzdem fortfahren“ wählen; die Verbindung ist danach trotzdem verschlüsselt.

          Die Domain muss auf deine öffentliche IP zeigen. Im Router Port 80 (für die Prüfung) und Port 443 auf Port 8420 dieses Rechners weiterleiten – dann ist das Panel unter https://deine-domain erreichbar. Das Zertifikat wird alle 60 Tage von selbst erneuert.

          Ausgesperrt? Auf dem Server selbst geht http://localhost:8420 immer, z. B. per SSH-Tunnel. Oder in /etc/systemd/system/gamepanel.service die Zeile Environment=GP_NO_TLS=1 ergänzen und den Dienst neu starten.

          Über einen Reverse Proxy

          Läuft das Panel hinter Traefik, nginx oder Caddy (z. B. unter https://panel.meine-domain.de), trag hier die Adresse des Proxys ein. Dann sieht das Panel die echte Adresse der Besucher (für Protokoll, Sitzungen und die Sperre nach falschen Passwörtern) und leitet nicht noch einmal auf HTTPS um.

          Allgemein

          KI-Assistent

          Du nutzt deinen eigenen API-Key. Die Kosten rechnet dein Anbieter direkt mit dir ab. Ollama läuft kostenlos auf deinem eigenen Rechner.

          Externe Backups

          Jedes Backup wird zusätzlich außerhalb dieses Servers gespeichert. Fällt die Platte aus, sind die Spielstände noch da.

          Steam-Konto

          Nur für Spiele, deren Server Steam nicht anonym herausgibt (Arma 3, DayZ, Killing Floor …). Das Panel speichert dein Passwort nicht, SteamCMD merkt sich nur die Anmeldung. Am besten ein eigenes Konto nur für Server nehmen: wer mit demselben Konto spielt, kann beim Server-Update aus dem Spiel fliegen. Manche Spiele (z. B. DayZ) verlangen, dass das Konto das Spiel besitzt.

          Steam-Web-API-Schlüssel für die Workshop-Suche (optional)

          Ohne Schlüssel sucht das Panel über die öffentliche Workshop-Seite. Mit Schlüssel ist die Suche genauer und schneller. Einen Schlüssel bekommst du kostenlos unter steamcommunity.com/dev/apikey (als Domain einfach den Namen deines Panels eintragen).

          Discord-Bot
          
    
          Ein eigener Bot für deinen Discord-Server: eine Statusnachricht, die sich selbst aktualisiert, und die Befehle /status, /start, /stop und /restart. /status darf jeder, starten und stoppen nur die Rollen und Personen unten.
          
    
          So richtest du den Bot ein (5 Minuten)
      
            
        
          1. Auf discord.com/developers/applications „New Application“ anlegen, z. B. „Bytewise Panel“.
            2. 
        
          2. Unter General Information die Application ID und den Public Key kopieren und unten eintragen.
            3. 
        
          3. Unter Bot „Reset Token“ klicken und den Token unten eintragen. Den Token niemandem zeigen.
            4. 
        
          4. Unter Installation bei „Guild Install“ die Scopes applications.commands und bot wählen, als Rechte „View Channels“, „Send Messages“ und „Embed Links“. Den Install-Link öffnen und den Bot auf deinen Discord-Server holen.
            5. 
        
          5. In Discord unter Einstellungen → Erweitert den Entwicklermodus einschalten. Dann Rechtsklick auf deinen Server, den Kanal für die Statusnachricht und die Rolle(n) → „ID kopieren“.
            6. 
        
          6. Unten speichern. Danach unter General Information bei „Interactions Endpoint URL“ diese Adresse eintragen und speichern:  Discord prüft sie sofort; das klappt nur, wenn das Panel von außen per HTTPS erreichbar ist (bei dir über Traefik).
            7.

          1. In AMP die Instanzen stoppen, die du übernehmen willst. Laufende Instanzen werden übersprungen, damit kein halb geschriebener Spielstand mitkommt.
            2. 
    
          2. Auf dem AMP-Rechner als root (su -) diesen Befehl ausführen. Er gilt zwei Stunden.
      
            …
            
      Nur bestimmte Instanzen: die Namen hinten anhängen, z. B. … --token … pw01 Icarus01.
            3. 
    
          3. Hier übernehmen: Jede empfangene Instanz erscheint unten. Name prüfen, „Übernehmen“ klicken, danach den Server starten.
